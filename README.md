# Лабораторная работа 1 - Управление энергетическим генератором

Студент: Бондарук Даниил Андреевич
Группа: Б9124-02.03.01сцт

Предметная область:
Приложение моделирует пульт управления генератором. 

Свойства и правила переходов:
У генератора четыре изменяемых свойства: 
1) Топливо 0–100 ед.
2) Температура ядра 20–120°C
3) Целостность корпуса 0–100% 
4) Cчётчик выработанной энергии МВт·ч.

Состояния объекта: 
Штатный режим, Ожидание (нехватка топлива), Критический перегрев (при температуре >= 85°C), Авария (при падении прочности корпуса до 0%).

Правила работы:
1) Форсаж: вырабатывает 50 МВт·ч, тратит 20 ед. топлива и нагревает генератор на 25°C. Доступен только при целом корпусе, запасе топлива >= 20 ед. и температуре <= 105°C. Если включить форсаж при перегреве (>= 85°C), корпус получает 35% урона.
2) Охлаждение: снижает температуру на 35°C и расходует 10 ед. топлива на насосы. Недоступно при базовой температуре (20°C) или нехватке топлива.
3) Заправка и Ремонт: по технике безопасности разрешены только на охлаждённом генераторе (<= 50°C), если корпус цел и соответствующий ресурс не полон.
4) Авария и Сброс: при падении прочности корпуса до 0% экран блокирует рабочие кнопки, меняет цветовую схему. Доступен сброс в исходное состояние.
